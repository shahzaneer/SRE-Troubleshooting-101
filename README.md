# SRE-Troubleshooting-101
**SRE-Troubleshooting-101** is a practical, open-source repository designed to serve as a real-world survival guide for Cloud, DevOps, and Site Reliability Engineers tasked with navigating high-pressure on-call rotations. Built specifically for system administrators, engineers, and tech professionals looking to master production-grade debugging, the repository bridges the gap between academic theory and chaotic production failures. It features curated, step-by-step runbooks, incident response playbooks, and diagnostic command cheat sheets for tools like Kubernetes and cloud providers. Ultimately, this repository is engineered to transform stressful, late-night infrastructure emergencies into structured, blameless, and systematic troubleshooting exercises.
